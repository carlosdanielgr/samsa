# Samsa Studio

This project uses **Vite** as a bundler and **Bun** as a package manager.

## Prerequisites

- Have installed [Bun](https://bun.com/get).
- Have installed [Node](https://nodejs.org/en/download).

## Installation and execution

1- **Install Bun (Windows PowerShell)**

```bash
powershell -c "irm bun.sh/install.ps1|iex"
```

2- **Install dependencies**

```bash
bun install
```

3- **Run the project in development mode**

```bash
bun run dev
```
